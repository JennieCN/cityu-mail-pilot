服务条款

版本 1.1 · 生效日期 2026-09-18 · 适用服务：CityU Mail Pilot

本服务条款（下称"本条款"）是你与 CityU Mail Pilot（下称"本服务"）运营者之间就使用本服务达成的协议。 请在使用前完整阅读本条款。你注册、配置或使用本服务，即表示你已阅读、理解并同意接受本条款全部内容的约束。

1. 服务说明

本服务读取你转发至私人邮箱的本校来信，调用大语言模型生成中文摘要报告，并以电子邮件方式发送至你指定的邮箱。 本服务对你的邮箱仅执行只读访问，不回复、不删除、不转发你的邮件给任何第三方，但下列第三方大模型服务商除外（见 隐私政策 第 3 节）。

本服务不是城大的官方服务。本服务由个人独立开发和维护，未获得香港城市大学（CityU）的授权、认可、委托或背书， 不是学校的信息系统或官方通知渠道，亦不代表学校立场。

本服务名称中的"CityU"仅用于说明所处理的来信来源，属事实描述，不构成任何形式的授权、合作或隶属关系。 本服务的域名、服务器、经费、数据、模型调用及全部技术决定均由运营者自行负责，与香港城市大学无关。 本服务出现问题时应向运营者提出，不应联系香港城市大学的 IT 支持部门，该部门不负责本服务。

2. 人工智能生成内容的性质与风险

报告由大语言模型自动生成，可能存在遗漏、误解或与事实不符的情形。

  1. 报告仅供参考，不构成学校或任何机构的官方通知。
  2. 一切以原始邮件为准。在涉及选课、考试、缴费、报名、签证、毕业、纪律处分等任何产生后果的决定前， 你应自行查阅并核对原始邮件。
  3. 因依赖报告内容而产生的任何损失，本服务不承担责任。

3. 邮件处理授权

你须自行确认有权实施下列处理行为，方可使用本服务。 本服务以你本人的授权为基础，不得用于规避任何适用的限制。

你开通本服务（包括在城大邮箱中设置自动转发、在「邮箱设置」中保存邮箱授权码、启用收信与报告生成）时， 即向运营者作出下列陈述与保证：

  1. 你有权将该邮箱中的邮件转发或复制至你在本服务中登记的私人邮箱；
  2. 你有权允许本服务读取、存储、解密与处理其中符合本校发件域的来信；
  3. 你有权将邮件内容发送给第三方大模型服务商（详见 隐私政策 第 3 节与第 13.1 节）；
  4. 如学校、雇主或任何他人对你有保密或不得外传的要求，你已取得所需许可， 或已确认该要求不适用于你交由本服务处理的邮件；
  5. 你不会使用本服务处理不是你的邮箱，亦不会处理你无权处理的邮件。

未确认上述各项者，不得开通或继续使用本服务。 界面上的授权确认勾选框即上述确认（见第 4 条第 8 项），勾选即表示你已逐项确认。

运营者无法代你作出上述判断。运营者不知悉你与学校之间的约定，亦无法判断每一封邮件是否包含第三人的个人资料。 授权由你本人确认并承担相应责任。如你不确定是否享有该项权利，请勿使用本服务，或先行取得明确许可； 你亦可仅使用自有 API key 并自行部署（见第 11 条），使邮件不经过运营者一侧。

4. 账号与用户责任

  1. 你仅可使用你本人的邮箱，不得使用本服务处理他人的邮箱。
  2. 你应妥善保管登录密码、邮箱授权码及 API key。该账号下的一切操作均视为你本人的行为。
  3. 内测期间默认使用管理员提供的模型 key，相关费用由管理员承担，你无需自备 key，亦无需支付任何费用。 管理员可随时终止内测或调整上述安排，并将提前通知。
  4. 联网核实功能同样默认使用管理员提供的搜索 key。启用该功能时，自邮件主题提取的检索词将发送至搜索服务商， 查询记录归属于管理员账号。你可填写自有搜索 key 予以覆盖。
  5. 你亦可改用自有 API key（于「AI 模型」中填写）。此后调用费用由你直接向服务商支付，调用记录仅归属于你本人。
  6. 使用管理员提供的 key 时，你的邮件正文将经由管理员的模型服务商账号处理。如不接受该安排， 请填写自有 key，或改用自托管部署。
  7. 你应确保自身有权将邮箱中的邮件内容发送给第三方大模型服务商。如学校或他人对你有保密要求，应先行确认。 此为使用本服务的前提，具体见第 3 条；运营者不代你作出判断，亦不承担代你取得授权的义务。
  8. 开通本服务前，你须在界面上勾选确认第 3 条的授权陈述与保证（于「邮箱设置」保存之前）。 未勾选者，服务端将拒绝保存邮箱设置，收信功能亦不会启动。

5. 禁止行为

存在下列行为之一的，账号将被立即停用：

  • 使用本服务处理不是你的邮箱，或未经授权获取他人邮件；
  • 将本服务用于任何违法用途，或试图借本服务规避学校信息系统的管理规则；
  • 以异常流量、异常请求或其他方式致使服务无法正常提供，影响其他用户；
  • 探测、扫描或攻击本服务及其服务器，或试图读取其他用户的数据；
  • 绕过内测人数上限或邀请机制进行批量注册。

6. 内测阶段的免责声明

  1. 本服务免费提供，处于内测阶段，由个人在业余时间维护。
  2. 本服务不作任何可用性承诺（无 SLA），可能随时中断、延迟、丢失邮件或发生错误。
  3. 本服务功能可能随时变更或移除；内测人数上限由运营者调整。
  4. 运营者将尽合理努力，但不保证报告按时送达，亦不保证你不会漏收重要邮件。 请勿将本服务作为你唯一的通知渠道。

7. 服务终止与数据处理

如本服务终止运营或需清空数据，运营者将：

  1. 至少提前 14 天通过你注册的邮箱发出通知；
  2. 在通知中提供不少于 14 天的数据导出窗口，你可在该期间内导出并留存报告与数据；
  3. 于窗口届满后删除服务器上的用户数据（含备份）。备份按时间滚动保留，服务器上留存最近 7 天， 超出该期间的副本将自动删除；如运营者启用异地备份，同一时间窗口同样适用于异地副本。

你亦可随时自行提前导出或删除数据，无需等待上述通知。

8. 用户终止使用

你可在「报告与账户」中一键导出或一键删除你的账号。账号删除后数据不可恢复。 你亦可发送邮件至 {{CONTACT_LINK}} 要求删除。

9. 账号停用

如你违反第 5 条，或你的使用明显危及本服务或其他用户，运营者可在不事先通知的情况下停用你的账号。 非紧急情形下，运营者将先行说明理由。
