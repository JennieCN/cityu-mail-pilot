01 · 待办事项

生成不同紧急程度的待办事项

邮件自己会说明它有多急。Mail Pilot 把这个信号原样带进清单，并写清判定的依据：谁发的、还剩多少时间、错过了会有什么后果。列表默认按重要程度排列。

重要

带明确的截止时刻，或者错过会影响选课、缴费、报名资格与固定日程。

一般

有明确时限但可以补救：能续借、能改约、还能补交，拖延的代价有限。

低

时限还远，或者只是通知类的内容。它照旧进清单，但不占你的注意力。

  • 把「本周内」「尽快」这类模糊说法，换成日历上的具体日期与时刻。
  • 勾好要办的条目，导出一份 .ics，截止时刻跟着条目一起进手机日历。
  • 不想再用时，关掉城大邮箱里的转发规则即可停止。
02 · 看原信

查看原件，AI 翻译，AI 总结

接入的是学校邮箱的只读权限：不删信、不回信、不改标签。你随时在校园邮箱后台撤销授权，摘要会立刻停止。

  • 需要核对时，从待办点回原始邮件。
  • AI 负责翻译和总结，原文一个字不改。
  • 邮件正文不留存，摘要生成后即弃。

我们只做一件事：读信、写摘要、发回给你。不帮你回信，不把数据给第三方，不用你的邮件训练模型。

授权 · 只读

只读令牌

用的是邮箱的授权码（不是登录密码），全程只读：不标记已读、不移动、不删除。 你可以随时在邮箱后台撤销它，撤销后我们立刻读不到。

留存 · 正文

正文不留存

报告发出后，我们这边不留邮件正文；跳过邮件的正文根本不入库。 留下来的只有元数据与你自己标记的待办状态。

训练 · 零

不用于训练

不用你的邮件训练任何模型，不卖、不共享给广告方，也没有任何遥测。 生成报告时正文会发给模型服务商——这一条写在下面那张披露框里，不藏着。

隐私说明

我们对你的邮箱做什么

下面写的是程序的实际行为，不是法律措辞。

  • 只读收信，不标记已读、不移动、不删除
  • 只处理本校邮箱发来的邮件，其余只记一行「已跳过」和发件人
  • 报告发出后，我们这边不留邮件正文
  • 邮箱授权码和 API key 加密保存；改密码后，其它设备上的登录会立刻失效
  • 不统计你的使用行为，也没有任何遥测
  • 不用你的邮件训练模型，不卖也不共享给广告方
  • 跳过的邮件不会悄悄消失，每一封都会写在日报里
你需要知道的一件事 生成报告时，邮件正文会通过加密连接发送给大模型服务商（如 DeepSeek、OpenAI、火山方舟）。 在另行通知前默认用管理员的 API key，所以这些调用记录会落在管理员的模型账号里； 换成你自己的 key 之后，记录就只在你自己名下。开启联网核实时还会从邮件主题提取检索词发给搜索服务商（豆包）， 用管理员的搜索 key 时这些查询记录同样落在管理员账号下。服务商受它自己的隐私政策约束， 我们无法替你保证它不用于训练。请不要用它处理你无法接受外传的内容。

报告由模型生成，会出错

它可能漏掉、误解或凭空写出内容。报告不是学校的官方通知。涉及选课、缴费、报名、签证、毕业 这些有后果的事，请自己打开原始邮件核对，一切以原邮件为准。

也可以自己部署

不想把邮件交给别人的机器，就自己装一份，那样邮件只经过你自己的服务器 （仓库和许可证见上面那节）。不想自己弄就在下面注册一个账号。

开始之前，你可能想问这些。

目前只支持从 CityU 校园邮箱转发过来；你要转发到的私人邮箱用哪家都行，见下面 Q5。

Q1

会读到我和老师的私人往来吗？

只会读到你从城大邮箱转发过来的信——转发规则是你自己设的，可以随时关掉。 不是本校邮箱（cityu.edu.hk）发来的邮件只记一行「已跳过」和发件人， 正文根本不进数据库；运营者也看不到任何正文。

Q2

摘要是中文还是英文？

你在这里选的那一种。报告用它写（来信本身是什么语言都不影响）， 最后再附一句另一种语言的简短小结。原文一个字不改， 想核对原信可以点任务上的「看原信」当场从你邮箱里读回来。

Q3

会用我的邮件训练模型吗？

不会。不训练、不人工逐封阅读、不卖给第三方，也没有遥测。 但要说清一件事：生成报告时正文会发给模型服务商（谁、发什么，见上面的披露框）。

Q4

要收费吗？

目前免费，默认用管理员提供的模型 key，你不花钱；也可以换成自己的 key， 费用与调用记录就都在你自己的服务商账号下。

Q5

我的邮箱能用吗？

QQ / 163 / 126 / Gmail / iCloud / Yahoo 这些都可以（要在邮箱设置里开启「收发邮件服务」并生成授权码）。 微软系（Outlook / Hotmail / Live）用不了——微软已停用授权码登录，这不是我们能改的。

Q6

报告会不会出错？

会。它由模型生成，可能漏掉、误解或凭空写出内容，报告不是学校的官方通知。 涉及选课、缴费、报名、签证、毕业的事，请以原邮件为准。

Q7

不想用了怎么办？

在「邮箱设置」里停用邮箱，或者删除账号；删除后邮件正文与报告一并清掉。 也可以只把城大邮箱里那条转发规则关掉——我们这边就再也收不到信了。

数据随时可以导出（「报告与账户」→ 导出我的数据，一份 JSON）；删除之后， 它会随备份那个 7 天的滚动窗口自然消失。

先创建账号

它本身是一个网页，所以「安装」跟装普通 App 不一样。 安卓可以下载安装包，也可以直接让浏览器装；iPhone 只能用 Safari 装到主屏幕。 iOS 不允许安装 App Store 以外的应用，这是苹果的限制，不是我们没做。

下面的图是示意图：颜色和位置可能跟你的手机略有差别， 作用是标出该点哪一个按钮。找不到时对着文字描述看。

安卓 · 方法一：下载安装包 功能最全

{{APK_BUTTON}}
  1. 下载：用手机上的浏览器打开这一页，点上面的下载按钮。文件会存进「下载」文件夹。
  2. 允许安装：点开刚下载的文件。系统会先拦一下，说不能安装未知来源的应用—— 点「设置」，找到你刚才用的那个浏览器，打开它的「允许安装未知应用」， 然后返回再点一次。
  3. 仍然安装：装的时候可能还会提示「Play 保护机制」或「未经检测的应用」。 这个安装包没有上架 Google Play，所以这类提示是正常的，选「仍然安装」就行。
  4. 以后更新：装好后桌面上会出现图标。以后有新版本，回到这一页重新下载、直接覆盖安装即可， 账号和数据都不会丢。

安卓 · 方法二：用浏览器直接装 最省事

不下载任何文件，也看不到「未知来源」的提示。

  1. 打开：用 Chrome 打开这一页。
  2. 安装：点右上角「⋮」，选「安装应用」；没有这一项就选「添加到主屏幕」。
  3. 确认：确认之后，桌面上就有图标了。

iPhone / iPad

iOS 装不了安装包，只能「添加到主屏幕」。加完之后是一个独立图标， 打开看不到地址栏，用起来和下载的 App 一样。

  1. 换到 Safari：必须用 Safari。在微信、QQ、Chrome 里都加不了。 先把这一页的网址复制下来，粘到 Safari 的地址栏里打开。
  2. 点分享：点屏幕最底下中间那个「分享」按钮——一个方框、里面一个向上的箭头。 如果在最底下找不到，就在页面顶部找。
  3. 添加到主屏幕：在弹出的菜单里往上滑，找到「添加到主屏幕」，点它。
  4. 添加：右上角点「添加」。回到桌面，就能看到新图标了。

怎么确认是真的装好了

从桌面图标打开时，看不到浏览器的地址栏，那才算装好了。 如果顶上还压着一条地址栏，说明打开的仍然是个网页，回到上面重做一次。
